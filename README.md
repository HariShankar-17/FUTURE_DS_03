# FUTURE_DS_03
## Task 3 – Marketing Funnel & Conversion Performance Analysis

### 📊 Project Overview
This project focuses on analyzing a **marketing funnel dataset** to identify **conversion drop-offs, channel performance, and opportunities to improve lead-to-customer conversion**.

The dashboard was built using **Power BI** and visualizes how users move through the marketing funnel from **view → cart → purchase**.

---

## 🎯 Task Objective
Analyze marketing funnel data to identify:

- Conversion drop-offs
- Marketing channel performance
- Opportunities to improve lead-to-customer conversion

---

## 🛠 Tools Used
- **Power BI** – Data visualization and dashboard creation
- **Excel / CSV Dataset** – Data source
- **GitHub** – Project documentation and version control

---

## 📈 Dashboard Overview

![Marketing Funnel Dashboard](dashboard/marketing-funnel-performance-dashboard.png)

The dashboard contains the following key components:

### KPI Metrics
- **Total Views:** 140K
- **Total Cart Adds:** 40K
- **Total Purchases:** 20K

These KPIs summarize the overall funnel performance.

---

### Conversion Funnel Analysis
The funnel chart shows the user journey:

View → Cart → Purchase

This visualization helps identify **where users drop off in the conversion process**.

---

### Channel Performance
The **Channel Performance chart** compares how different marketing channels contribute to user engagement.

Channels analyzed:
- Google Ads
- Instagram
- Organic Search
- Email
- Referral

---

### Revenue by Channel
This visualization highlights **which marketing channels generate the most revenue**.

---

### Purchase Trend Over Time
The **Purchases Over Time chart** shows daily purchase activity and helps identify patterns or fluctuations in customer behavior.

---

### Interactive Filtering
The dashboard includes a **Channel filter**, allowing users to explore funnel performance by individual marketing channels.

---

## 🔍 Key Insights
- The largest drop-off occurs between **View and Cart**, indicating that many users view products but do not proceed to add them to the cart.
- **Google Ads** drives the highest number of interactions and conversions.
- **Referral traffic** shows the lowest performance compared to other channels.
- Purchase activity remains relatively **stable over time with minor fluctuations**.

---

## 💡 Recommendations
- Improve **product page engagement** to increase add-to-cart actions.
- Invest more marketing budget into **high-performing channels such as Google Ads and Instagram**.
- Optimize or reevaluate **low-performing channels such as Referral traffic**.
- Consider implementing **promotional offers or clearer call-to-action buttons** to improve cart conversions.
